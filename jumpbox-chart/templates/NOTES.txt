【1】查看 Pod 状态:
  kubectl get pods -n {{ .Release.Namespace }} -l app.kubernetes.io/instance={{ .Release.Name }}

【2】进入跳板机 (交互式 shell):
  kubectl exec -it -n {{ .Release.Namespace }} {{ include "jumpbox.fullname" . }}-0 -- zsh

【3】连接数据库:
  db-connect mysql       # 连接 MySQL
  db-connect postgres    # 连接 PostgreSQL
  db-connect redis       # 连接 Redis
  db-connect info        # 查看连接信息

【4】手动执行备份:
  backup-all             # 全部备份
  backup-mysql           # 仅 MySQL
  backup-postgres        # 仅 PostgreSQL
  backup-redis           # 仅 Redis

【5】kubectl 节点操作 (已配置 RBAC):
  kubectl get nodes
  kubectl describe node <节点名>
